# Changelog

## 0.2.0-alpha.1

- Renamed and packaged as **Spherical World Border**.
- Added configurable on-screen boundary approach warnings.
- Added configurable client-side visible boundary shimmer.
- Default planet circumference set to 1,000,000 blocks.
- Retained spherical pole transform: latitude reflection plus 180° longitude shift.
- Retained east/west longitude wrapping.
- Added Create entity safety exclusion option.

## 0.1.0-alpha.1

- Initial spherical boundary prototype.
- East/west wrapping.
- North/South pole reflection with half-circumference longitude shift.
